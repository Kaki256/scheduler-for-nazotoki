# マイグレーションおよびリファクタリング報告書

本ドキュメントは、パッケージマネージャーのBunへの移行、ドキュメント駆動開発(DDD)基盤の構築、重大なセキュリティ脆弱性の修正、およびチーム編成アルゴリズムのバックエンド移行（ベストエフォート化）に関する一連の作業記録と設計意図をまとめたものです。

## 1. パッケージマネージャーのBun移行と環境整備

### 実装動機

`AGENT.md` の厳格な要求に基づき、ツールチェーンを `bun` に統一する必要がありました。既存のプロジェクトは `pnpm` に依存しており、Dockerコンテナのビルド環境も `npm` を使用していたため、これらを完全にBunベースへ刷新しました。

### 変更内容

* **ツールチェーンの置換**: `pnpm-lock.yaml` および `pnpm-workspace.yaml` を削除。
* **ワークスペース対応**: ルートの `package.json` に `"workspaces": ["frontend", "backend"]` を追加。
* **Docker環境の刷新**: `frontend/Dockerfile` と `backend/Dockerfile` のベースイメージを `oven/bun:latest` に変更し、コマンドを `bun install` および `bun run` に統一。

## 2. ドキュメント駆動開発 (DDD) の土台構築と仕様の整合

### 実装動機

プロジェクトの設計ドキュメントが存在せず、仕様変更時のプロセスが破綻していました。また、初期に作成したドキュメントと実際のコード（DBスキーマやAPIエンドポイント）に乖離があったため、稼働しているコードを正としてドキュメントを再定義しました。

### 変更内容

* **ドキュメントの新規作成**: `docs/` ディレクトリを新設し、以下のファイルを配置。
  * `DATA_MODEL.md`: データベースのテーブル設計（主キーを `event_url` に統一）。
  * `PRODUCT_DESIGN.md`: フロントエンドのUI/UX方針。
  * `API_SPEC.md`: APIエンドポイントの仕様。
* **エンドポイントの責務分離**: スクレイピング取得用 (`/api/get-schedule`) とサマリー取得用 (`/api/events/.../summary`) のAPI分離をドキュメントに反映。

## 3. 認証・セキュリティ脆弱性の修正

### 実装動機

フロントエンドからAPIへ `username` をクエリやペイロードで自己申告して送信する設計になっており、**悪意のあるユーザーがリクエストを書き換えることで他人の出欠状況を閲覧・改ざんできる「なりすまし」の脆弱性**が存在していました。

### 変更内容

* **バックエンド**: `/api/save-my-status` と `/api/load-my-status` において、リクエストボディやクエリからの `username` 取得を廃止。リバースプロキシが付与するヘッダー（`x-showcase-user` 等）から抽出した安全な値 (`req._constructedUsername`) を排他的に使用するように修正。
* **フロントエンド**: 該当APIの呼び出し処理から `username` パラメータを削除。

## 4. チーム編成ロジックのバックエンド移行とベストエフォート化

### 実装動機

チーム編成の全探索アルゴリズムがフロントエンド（`EventSummaryPage.vue`）に記述されており、20〜30人規模のイベント時に**組み合わせ爆発によるブラウザのフリーズやサーバーのタイムアウト（504 Gateway Timeout）**が避けられない構造になっていました。

### 変更内容

* **バックエンド API化 (`POST /api/calculate-teams`)**: 重い計算ロジックをバックエンドに移植。
* **ベストエフォート・アルゴリズム（安全装置の導入）**: 探索ループ内に `Date.now()` による時間計測を導入し、**最大5秒（5000ms）**で探索を強制的に打ち切るタイムアウト処理を実装。計算が途中で終了した場合でも、その時点で見つかった上位の編成案を返すことで、実用性とシステムの安定性を両立。
* **フロントエンドの軽量化**: `EventSummaryPage.vue` からアルゴリズム関連のコードを全て削除し、APIを呼び出して結果を描画するだけのクリーンなViewコンポーネントにリファクタリング。ユーザー不安を軽減するため、計算時間がかかる旨をローディングUIに明記。
